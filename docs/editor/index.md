# Use the editor

**Tetragrama** is the native editor built on ZEngine. It provides the working
surface for asset management and scene authoring; Zodiac Engine Hub launches
projects with the selected engine version.

The editor is part of the engine's source tree and is built into the `Obelisk`
application. Its runtime and rendering contracts are documented in the
[engine reference](../reference/architecture.md).
