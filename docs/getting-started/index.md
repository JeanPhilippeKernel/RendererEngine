# Get ZEngine

The normal way to install and manage ZEngine is through **Zodiac Engine Hub
(Panzerfaust)**. It downloads installed engine versions and manages the project
configuration that ZEngine consumes at launch.

<div class="grid cards" markdown>

- :material-download: [**Install with Zodiac Engine Hub**](install-with-zodiac-engine-hub.md)

  Download the Hub, select a ZEngine version, and install it.

- :material-folder-plus-outline: [**Create your first project**](first-project.md)

  Create or open a project from the Hub, then launch it with the selected engine.

- :material-update: [**Update safely**](update-and-migration.md)

  Review release notes and migration instructions before changing engine versions.

- :material-laptop: [**Check supported platforms**](supported-platforms.md)

  See the platforms covered by the engine and the source-build matrix.

</div>

If you are contributing to the engine or need a local build, continue to
[Develop with ZEngine](../development/index.md).
